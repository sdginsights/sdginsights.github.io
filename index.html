1. The Differential Operator D and Linearity

The symbol $D$ denotes differentiation: $D = d/dx, D^2 = d^2/dx^2$. The linearity property states that for constants $a, b$ and differentiable functions $f, g$:

D[a f(x) + b g(x)] = a D[f(x)] + b D[g(x)]

This allows polynomial operators $L(D) = a_2 D^2 + a_1 D + a_0$ to be treated algebraically.

2. First-Order ODE Classification

Separable equations: Can be written as $M(x)dx + N(y)dy = 0$. Integrated directly on both sides.

MTH401: Solved Short & Long Problems

Short Question [3 Marks] Handout Solved

State the conditions for a first-order ODE to be exact.

Solution: The equation $M(x, y)dx + N(x, y)dy = 0$ is exact if and only if $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$ in the domain of definition.
