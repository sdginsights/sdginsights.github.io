Introduction to Differential Equations

100% Handout-Accurate Step-by-Step Solved Theory.

In classical algebra, the unknown quantity is always a scalar number. In Differential Equations, the unknown is never a single number—the unknown is an entire continuous function $y = f(x)$ that describes rates of change.

✎ SDG Insights Rough Work / Key Concept:

Notice that differentiation annihilates constants: d/dx(C) = 0. Therefore, integration must always restore the arbitrary constant C, representing the full family of solution curves!

Differential Operator D and Linearity

The symbol $D$ denotes differentiation with respect to $x$. The linearity property states that for constants $a, b$ and differentiable functions $f, g$:

D[a f(x) + b g(x)] = a D[f(x)] + b D[g(x)]
