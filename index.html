In classical algebra, the unknown quantity is always a scalar number. In Differential Equations, the unknown is an entire function $y = f(x)$ describing continuous rates of change.

✎ SDG Insights Rough Work / Key Concept:

Notice that differentiation eliminates constants: d/dx(C) = 0. Therefore, integration must always restore the arbitrary constant C!

Differential Operator D and Linearity

The symbol $D$ denotes differentiation with respect to $x$. The linearity property states:

D[a f(x) + b g(x)] = a D[f(x)] + b D[g(x)]
